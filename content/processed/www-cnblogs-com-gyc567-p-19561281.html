注意：个人微信（普通微信）目前官方不支持，因为微信个人版没有开放 Bot API。只有企业微信（WeCom）可以通过第三方插件支持。如果你用的是普通微信，建议优先用 Telegram（体验最好）。如果必须用企业微信，可以参考社区插件，但步骤较复杂，新手不推荐。 下面是详细教程，我会一步一步带你操作，即使零基础也能看懂。 第一部分：连接 Telegram（强烈推荐，超级简单！） Telegram 是 OpenClaw 最受欢迎的连接方式，支持手机随时随地控制 AI，延迟低、稳定。 步骤 1：创建 Telegram Bot（获取 Token） 打开你的 Telegram App（手机或电脑版都行，没有账号先注册，需要手机号）。 在搜索框搜索 @BotFather（官方机器人管理器），点击进入聊天。 发送命令 /newbot。 BotFather 会让你设置机器人名字（显示名，随便起，比如 “MyOpenClawBot”）。 再设置用户名（必须以 “bot” 结尾，且全局唯一，比如 “my_openclaw_2026_bot”）。 成功后，BotFather 会给你一个 API Token（长字符串，像 123456789:ABCdefGHIjklMNOpqrsTUVwxyz），复制保存好，后面要用！ 可选：搜索 @userinfobot，发送 /start，它会告诉你你的 Telegram 用户 ID（数字），备用。 步骤 2：安装/启动 OpenClaw 并配置 Telegram（如果已安装跳过安装部分） 如果你还没安装 OpenClaw，先运行一键安装： curl -fsSL https://openclaw.ai/install.sh | bash 然后运行配置： openclaw onboard （或如果已经安装过，直接运行 openclaw configure） 在配置向导中： 选择模型（推荐 Minimax 或 Anthropic）。 当问到 messaging channel 时，选择 Telegram (Bot API)。 输入刚才从 BotFather 获取的 Bot Token。 继续完成其他配置（API Key 等）。 如果是用 VPS 部署（如 Zeabur 或其他云平台）： 在环境变量中添加 TELEGRAM_BOT_TOKEN=你的token。 重启服务。 步骤 3：配对（Pairing）连接你的账号 在 Telegram 中搜索你刚创建的 Bot 用户名，进入聊天。 发送 /start。 Bot 会回复一个配对码（pairing code，像 JN4MSY23 这样的字符串）。 回到你的 VPS/终端（或 OpenClaw Web 面板的聊天框），输入命令批准： openclaw pairing approve telegram 你的配对码 （比如 openclaw pairing approve telegram JN4MSY23） 或者在 Web UI 聊天框直接输入：openclaw pairing approve telegram 你的配对码 成功后，你会看到 “Approved telegram sender...” 的提示，Telegram 中也会确认。 步骤 4：测试连接 在 Telegram Bot 聊天框发消息，比如 “你好，你是谁？” 或 “帮我查天气”。 如果 AI 正常回复，恭喜成功！现在你可以用手机随时控制 OpenClaw 了。 小贴士： 支持群聊：把 Bot 拉进群，也能@它使用。 如果想多个账号连接，重复 pairing 步骤。 问题排查：运行 openclaw status 查看服务状态，或 openclaw logs 查看日志。 第二部分：连接微信（仅限企业微信，不支持个人微信） 根据 OpenClaw 官方文档和 GitHub，目前不支持普通个人微信（因为微信个人版没有开放开发者 API，无法创建 Bot）。 如果你有企业微信（公司用的那种），可以通过社区第三方插件支持： 去企业微信管理后台创建应用，获取 CorpID、AgentID、Secret 等。 安装插件：npm install openclaw-plugin-wecom（或社区指南）。 配置插件参数。 重启 OpenClaw。 详细步骤较复杂，且需要企业认证，建议新手直接用 Telegram（功能完全一样，甚至更好）。 如果未来官方支持个人微信，我会第一时间更新教程！ 常见问题 连接失败：检查 Token 是否正确，服务是否运行（openclaw start）。 安全提醒：Bot Token 很重要，不要泄露。Pairing 后只有批准的账号能用。 多平台：OpenClaw 还支持 WhatsApp、Discord、Slack 等，步骤类似（WhatsApp 用 QR 码扫码）。 更新：运行 openclaw update 保持最新。 恭喜！你现在可以用 Telegram 随时随地和你的 OpenClaw AI 助手聊天啦！ 本人公众号：比特财商
