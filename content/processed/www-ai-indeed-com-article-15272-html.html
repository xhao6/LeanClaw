Moltbot 最终定名为 Openclaw，但这丝毫未减其在 AI 圈的热度。它不仅是一个聊天机器人，更是能接管电脑的“全能代理”。 本文将围绕 Openclaw，从产品介绍、官网资源、国产平替方案（实在Agent）、本地/云端部署教程四个维度，带来全方位解析。 一、Openclaw 是什么？ 【项目背景】 Openclaw 是由奥地利知名开发者 Peter Steinberger 发起的开源 AI Agent 项目。 初期孵化（2025.10-11）：原计划为 Twitter 分析工具，意外演变为 AI 代理。 正式爆发（2026.01）：项目更名为 Clawdbot 发布，24小时内斩获 9,000 Star，一周突破 60,000 Star，获 AI 大神 Andrej Karpathy 高度评价。 最终定名：因 Clawdbot 与 Claude 发音撞车，历经 Moltbot（寓意蜕变），最终定名为 Openclaw。 【核心功能】 Openclaw 是一个开放代理平台，不同于存储在 SaaS 服务器上的传统助理，它运行在你自己的设备（Mac mini、VPS 或家用电脑）上。 全渠道交互：支持 WhatsApp, Telegram, Slack, Teams 等，国产化方面可接入钉钉、飞书。 最新特性：支持 Kimi K2.5、小米 MiMo-V2-Flash 模型；支持图片交互；代码库经过 34 次安全加固。 【核心优势】 全天候待命：在低功耗设备上 24 小时运行。 长期记忆：通过本地 Markdown 文件存储偏好，越用越懂你。 跨平台操控：身在户外，通过手机发指令，家里的电脑就能自动写代码、整理文档。 二、Openclaw 官方资源导航 官网：https://openclaw.ai/ GitHub：https://github.com/openclaw/openclaw 官方文档：https://docs.openclaw.ai/start/getting-started Discord：https://discord.com/invite/clawd Note：访问上述网站可能需要网络环境支持。 三、Openclaw 国产最佳平替：实在 Agent 对于国内企业和用户，配置开源项目门槛较高。 2026年1月29日，专注 AI Agent 的厂商“实在智能”上线了实在 Agent V7.3.1 无界版。 它更懂中国办公场景，无需复杂的服务器部署，通过钉钉/飞书即可远程操控电脑，安全、稳定、零代码。 【配置前准备】 下载软件：安装实在 Agent V7.3.1 无界版（目前支持 Windows）。 控制端：手机安装钉钉、飞书或塔斯 AI 助理 APP。 【配置流程 A：TARS 智能助理初始化】 打开实在 Agent 客户端 -> 设置中心 -> Agent 设置。 勾选启用 【无界】TARS 智能助理。 （可选）扫描二维码下载“塔斯 AI 助理”APP，登录同账号即可使用。 【配置流程 B：钉钉远程控制】 1.创建应用：登录钉钉开发者平台，创建企业内部应用。 2.获取凭证：在“凭证与基础信息”中复制 Client ID 和 Client Secret。 3.绑定 Agent：回到实在 Agent 设置页，点击“钉钉凭证配置”，填入上述 ID 和 Secret。 4.配置机器人： 在钉钉后台开启机器人，消息接收模式选择 Stream 模式。 开通“企业内机器人发送消息”权限。 发布应用。 5.开始使用：在钉钉搜索机器人名称或将其拉入群聊，@它 即可下达指令。 【配置流程 C：飞书远程控制】 1.创建应用：登录飞书开放平台，创建“企业自建应用”。 2.获取凭证：复制 App ID 和 App Secret。 3.绑定 Agent：回到实在 Agent 设置页，点击“飞书凭证配置”，填入上述信息。 4.配置机器人： 添加“机器人”能力。 事件配置：选择“使用长连接接收事件”，添加“接收消息”事件。 权限管理：开通机器人消息相关权限。 创建并发布版本。 5.开始使用：在飞书搜索应用或群聊 @它，即可远程操控电脑。 【FAQ：为什么选择实在 Agent？】 更简单：无需程序员视角的命令行操作，下载即用。 更本土：完美适配钉钉、飞书、企微（适配中）生态。 更安全：内置高危操作智能围栏，数据本地化，杜绝泄露。 成本低：无需租赁云服务器，利用现有办公电脑即可。 关于费用：社区版免费；企业版支持更多高级功能，新用户注册即赠送免费资源点。 四、Openclaw 安装部署教程
