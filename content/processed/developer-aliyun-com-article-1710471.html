3个工作日，建议提前规划好时间。未完成实名认证的账号，将无法购买云服务器和开通百炼大模型的相关功能，务必确保这一环节提前完成。同时，需保证账号余额充足，或已开通按量付费权限，以覆盖服务器租用及后续模型调用可能产生的费用。 （二）服务器配置选型 此次部署推荐使用轻量应用服务器，其操作界面简洁、运维成本低，非常适配个人与小型团队的使用场景。平台针对OpenClaw预设了基础推荐配置：2vCPU、2GiB内存、40GiB ESSD系统盘以及200Mbps峰值带宽。这一配置足以支撑邮件整理、文档生成、简单任务拆解等日常操作。若需要处理多工具并发调用、大数据分析或长时间不间断的复杂任务，可选择升级至4vCPU + 4GiB内存的配置，以保障运行流畅性。 阿里云快速部署 OpenClaw 教程 第一步：前往阿里云OpenClaw一键部署专题页面：https://www.aliyun.com/activity/ecs/clawdbot，找到并点击【一键购买并部署】 第二步：购买阿里云轻量应用服务器，配置参考如下： 镜像：OpenClaw(Moltbot)镜像（已经购买服务器的用户可以重置系统重新选择镜像） 实例：内存必须2GiB及以上。 地域：默认美国（弗吉尼亚），目前中国内地域（除香港）的轻量应用服务器，联网搜索功能受限。 时长：根据自己的需求及预算选择。 第三步：访问阿里云百炼大模型控制台，找到密钥管理，单击创建API-Key。 前往轻量应用服务器控制台，找到安装好OpenClaw的实例，进入「应用详情」放行18789端口、配置百炼API-Key、执行命令，生成访问OpenClaw的Token。 端口放通：需要放通对应端口的防火墙，单击一键放通即可。 配置百炼API-Key，单击一键配置，输入百炼的API-Key。单击执行命令，写入API-Key。 配置OpenClaw：单击执行命令，生成访问OpenClaw的Token。 访问控制页面：单击打开网站页面可进入OpenClaw对话页面。 地域选择上也有诸多讲究。美国（弗吉尼亚）、中国香港等海外及港澳台地域的服务器无需进行ICP备案，购买完成后可直接启用，且联网功能不受限制；而国内的华东1（杭州）、华北2（北京）等地域，必须完成ICP备案后才能正常访问，这一点需要特别注意，避免因未备案导致部署后无法使用。 （三）核心凭证提前筹备 API - Key是OpenClaw调用百炼大模型的核心授权凭证，没有它，AI助手将无法实现自然语言理解和任务规划等核心功能。用户需提前登录百炼大模型服务平台，后续部署过程中会用到该凭证。此外，若计划通过钉钉、Telegram等第三方工具与OpenClaw进行交互，还需提前准备好对应平台的通信Token，如钉钉的APP KEY、Telegram的Bot Token等，为后续通信通道配置做好准备。 二、阿里云OpenClaw一键部署实操步骤 2026年推出的一键部署方案，核心优势在于借助预置的OpenClaw专属镜像，跳过手动安装依赖、配置运行环境等复杂步骤。其中，轻量应用服务器部署路径因适配性强、操作简便，成为多数用户的首选，具体步骤如下。 （一）服务器实例创建与镜像部署 首先，可通过平台OpenClaw云服务专属页面直接进入部署界面，也可登录官网后，按照“产品→人工智能→OpenClaw云服务”的路径找到部署入口。首次使用的用户需要仔细阅读《OpenClaw服务协议》，勾选“已阅读并同意”后进入实例配置页面。 在镜像选择环节，需切换至“应用镜像”分类，搜索并选中“OpenClaw（原Moltbot/Clawdbot）”镜像。该镜像基于Alibaba Cloud Linux 3.2104 LTS 64位系统构建，已预装Python 3.9、Node.js 22及OpenClaw运行所需的各类依赖库，无需用户再手动进行环境配置。 完成镜像选择后，确认实例规格、地域等参数，接着进入网络配置环节。系统默认会启用公网IP，这是后续访问和管理OpenClaw的关键，防火墙选择默认安全组即可。随后在系统配置中设置服务器登录密码，密码需包含大小写字母、数字和特殊符号，以保障服务器安全。最后核对订单信息，点击“立即支付”，支付完成后系统将自动创建实例并部署镜像。这个过程大约需要1 - 3分钟，用户只需等待实例状态从“创建中”变为“运行中”即可。此时务必进入云服务器控制台，记录下该实例的公网IP地址，后续的配置操作都离不开这个核心凭证。 对于已有服务器的用户，无需重复购买，可登录控制台找到目标实例，执行“重置系统”操作，在镜像列表中选择OpenClaw专属镜像即可。但需特别注意，重置系统会清空系统盘中的所有数据，一定要提前做好重要数据的备份工作。 （二）服务器端口放通配置 实例运行后，进入轻量应用服务器控制台，找到已创建的OpenClaw实例，点击进入“应用详情”页签。OpenClaw默认的通信端口为18789，为了让外部设备能够正常访问，需要放行该端口。好在平台提供了“一键放通”功能，用户只需点击对应按钮，系统就会自动配置防火墙规则，无需手动编写复杂的命令。端口放通后，可尝试在浏览器中输入公网IP进行初步访问，若页面能正常加载，说明服务器端的基础部署已经成功。若页面无法打开，可先检查实例是否处于“运行中”状态，再核对端口是否放通成功。 三、核心配置：对接百炼大模型 OpenClaw本身不自带大语言模型，其理解自然语言、拆解任务流程的核心能力，需通过对接阿里云百炼大模型实现，而API - Key的配置就是完成这一对接的关键步骤。 （一）获取API - Key 打开百炼大模型服务平台，使用部署OpenClaw的同一账号登录。在平台导航栏中找到“密钥管理”页面，该页面默认地域多为华北2（北京），不同地域的API - Key相互独立。为了降低调用延迟，建议选择与云服务器地域邻近的节点。点击页面中的“创建API - Key”，系统会自动生成一组包含Access Key ID和Access Key Secret的密钥。生成后立即点击复制，将这两组密钥保存到本地的记事本或加密文档中。这组密钥是调用大模型的核心凭证，一旦泄露可能导致模型调用额度被盗用，若怀疑密钥泄露，需第一时间在平台上禁用旧密钥并重新创建。 （二）配置并验证API - Key 在浏览器地址栏输入“http://云服务器公网IP:18789”，回车后进入OpenClaw的配置中心。在左侧导航栏中找到“大模型配置→阿里云百炼”选项，将之前保存的Access Key ID和Access Key Secret分别粘贴到对应的输入框中，随后点击“测试连接”。 若页面弹出“连接成功，API - Key配置有效”的提示，说明对接成功，此时点击页面底部的“保存配置”即可。系统会自动重启OpenClaw服务以应用配置，重启过程大约需要30秒，期间页面可能会出现短暂无法访问的情况，属于正常现象，耐心等待即可。若测试连接失败，可从三个方面排查问题：一是检查密钥字符是否完整，是否存在多输、少输或误输入空格的情况；二是确认账号是否有可用的百炼模型调用额度，新用户通常可领取免费额度，可登录平台查看；三是核对服务器地域与API - Key所属地域是否匹配，地域不匹配可能会导致连接超时。 四、功能验证与个性化设置 完成上述配置后，还需进行功能测试和基础设置，确保OpenClaw能正常使用并适配个人需求。 （一）登录与基础验证 服务重启完成后，刷新OpenClaw页面，首次登录需要设置管理员密码，建议设置复杂度较高的密码并妥善保管。部分部署路径中，系统会通过“执行命令”自动生成访问Token，此时需输入对应的Token完成登录。登录成功后，可发送简单的测试指令，比如“帮我生成一份周工作计划模板”“整理一封主题为工作汇报的邮件框架”等，若OpenClaw能在短时间内给出符合要求的回复，说明核心功能已正常启用。 （二）通信通道拓展配置 为了使用户能在熟悉的工具中便捷操作OpenClaw，它支持对接多种即时通讯与办公协作工具，用户可根据自身习惯进行配置。以钉钉为例，登录OpenClaw后台，在“通信配置”中找到钉钉对接入口，输入提前准备好的钉钉APP KEY，完成绑定后，即可通过钉钉发送指令并接收任务执行结果。同理，Telegram用户可输入Bot Token完成绑定，企业用户也可对接企业微信、飞书等办公软件，实现办公场景与AI助手的无缝衔接。 （三）个性化参数调整 OpenClaw具备持久记忆功能，用户可在设置中配置个性化偏好。比如设定常用的文件存储路径，后续AI生成的文档会自动保存到对应位置；录入个人工作习惯，如汇报文档的常用格式、日程提醒的时间偏好等，AI助手会根据这些信息生成更贴合需求的结果。同时，可设置任务执行后的通知方式，如邮件通知、软件弹窗提醒等，避免错过重要任务的执行反馈。 五、常见问题排查与实用技巧 （一）常见问题解决办法 在部署和使用过程中，难免会遇到一些小问题，以下是几种高频问题的排查方案。其一，若无法访问OpenClaw页面，除了检查实例状态和端口配置，还可尝试更换Chrome或Edge等主流浏览器的最新版本，老旧浏览器可能存在兼容性问题。其二，若AI助手无法执行任务，大概率是API - Key失效或额度耗尽，可登录百炼平台检查密钥状态和剩余额度，必要时重新创建密钥。其三，若出现任务执行卡顿，可查看服务器资源占用情况，关闭不必要的后台进程，或考虑升级服务器配置。 （二）实用使用技巧 为了充分发挥OpenClaw的作用，这里有几个实用技巧。一是利用其自动化工作流功能，通过可视化配置组合多个工具，比如设置“监控指定文件夹→新文件上传自动备份至云存储→发送备份通知”的流程，减少重复操作；二是对于本地有隐私数据处理需求的用户，可在部署后切换至本地存储模式，确保敏感数据不泄露；三是定期备份OpenClaw的配置文件，当需要迁移服务器或重装系统时，可快速恢复之前的个性化设置，无需重新配置。 OpenClaw的阿里云一键部署方案，极大地降低了智能AI助手的使用门槛。无论是职场人士用于简化办公流程，还是小型团队用于提升协作效率，这款工具都能凭借其强大的自动化能力发挥重要作用。按照上述步骤操作，零基础用户也能快速拥有专属的AI助手，在减少人工干预的同时，显著提升任务处理效率。且其开源特性也为有进阶需求的用户预留了拓展空间，可根据自身需求集成第三方模型与插件，解锁更多个性化功能。 你的云 目录 热门文章 最新文章 为什么选择阿里云什么是云计算全球基础设施技术领先稳定可靠安全合规分析师报告大模型千问大模型大模型服务AI应用构建产品和定价全部产品免费试用产品动态产品定价配置报价器云上成本管理技术内容技术解决方案帮助文档开发者社区天池大赛阿里云认证权益免费试用解决方案免费试用高校计划5亿算力补贴推荐返现计划服务基础服务企业增值服务迁云服务官网公告健康看板信任中心关注阿里云关注阿里云公众号或下载阿里云APP，关注云资讯，随时随地运维管控云服务联系我们：4008013260法律声明Cookies政策廉正举报安全举报联系我们加入我们友情链接阿里巴巴集团淘宝网天猫全球速卖通阿里巴巴国际交易市场1688阿里妈妈飞猪阿里云计算万网高德UC友盟优酷钉钉支付宝达摩院淘宝海外阿里云盘淘宝闪购© 2009-现在 Aliyun.com 版权所有 增值电信业务经营许可证： 浙B2-20080101 域名注册服务机构许可： 浙D3-20210002浙公网安备 33010602009975号浙B2-20080101-4
