# LeanClaw v0.4 更新日志

**发布日期**：2026-03-20

---

## 🎉 新功能

### 返回键拦截跳转
- 新增 `useBackButtonRedirect` composable，自动拦截返回键
- 在"学习"、"发现"、"我的"页面按返回键时，自动跳转到首页
- 首页按返回键正常退出小程序，不被拦截

### batchUpdate 云函数
- 专用云函数支持批量增量更新 NoSQL 数据库
- 支持三种操作：`addFields`（添加字段）、`removeFields`（移除字段）、`replaceValue`（替换值）
- 使用 MongoDB `$set` 操作符避免字段丢失
- 管理后台功能，仅管理员可调用

### 清除缓存功能
- 在"我的"页面添加清除缓存入口
- 使用 CacheService 统一管理缓存逻辑

### 证书功能优化
- 支持保存证书到手机相册
- 进度条显示优化
- 底部提示文字颜色改为深色

### 学习页自动登录
- 未登录用户在学习页看到登录提醒横幅
- 点击"去登录"直接跳转到个人中心触发登录

---

## 🔧 优化改进

### 推荐系统
- 实现混合推荐算法：热度分 + 用户收藏状态 + 随机因子
- 分数计算：`score = heat * 10 + (已收藏 ? 50 : 0) + random() * 20`
- 未收藏高热度文章优先展示
- 使用日期种子确保排序稳定

### 收藏功能
- 收藏数据完整同步到云端
- 传递完整收藏数据（包含 stars 字段）
- 登录成功后自动同步云端收藏数据

### 徽章系统
- 完成课程后自动检查并解锁对应徽章
- 同步云端进度后自动解锁徽章

### 内容同步工作流
- 增强 AI 处理逻辑
- 添加导读和转载出处功能
- 支持 markdown 渲染

### 页面优化
- 首页快捷入口改为：精选案例、Skills大全、我的收藏
- 发现页支持 URL 参数设置初始 tab（`?tab=skill`）
- 学习统计页移除不完整的学习时长和连续打卡展示
- 优化证书界面样式与内容
