### ⚠️ NoSQL 数据库 Update 操作必读

使用 `writeNoSqlDatabaseContent` 的 `update` 操作时，**只更新指定字段会导致其他字段丢失**（部分更新模式）。

**正确做法**：在 update 对象中包含所有必要字段，确保记录完整。

```javascript
// ✅ 完整更新示例
update({
  "title": "新标题",
  "desc": "描述内容",
  "type": "skill",
  "markdownUrl": "https://xxx.tcb.la/content/xxx.md",
  "tags": ["标签1", "标签2"],
  "heat": 0,
  "image": "",
  "url": "",
  "source": ""
})
```

## ⚠️ 错误复盘（2026-03-19）

### 犯过的错误

1. **错误假设 MCP 工具的 update 是增量更新**
   - 误以为 `writeNoSqlDatabaseContent` 的 update 操作只会修改指定字段
   - 实际上：它是全量替换，会导致其他字段丢失

2. **盲目批量更新，未先验证**
   - 直接批量更新了 16 条 type=skill 记录
   - 结果：16 条记录的其他字段全部丢失

3. **未理解文档说明就操作**
   - 文档明确说明"只更新指定字段会导致其他字段丢失"
   - 但没有仔细阅读并执行

4. **两次犯同样错误**
   - 第一次更新 type=skill 时用单字段更新，丢失数据
   - 第二次更新 type!=skill 时又用单字段更新，再次丢失数据

### 教训

1. **更新前必读文档**：任何数据库操作前必须先读取并理解操作规范
2. **先验证再批量**：先用一条记录测试，确认安全后再批量操作
3. **使用完整字段更新**：必须包含记录的所有字段，而非只更新需要修改的字段
4. **更新后验证**：操作完成后查询确认数据完整性
