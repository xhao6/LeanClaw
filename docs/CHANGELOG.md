# LeanClaw 改动日志

本文档汇总 LeanClaw 小程序的历次功能变动。

---

## 2026-03-18

### 新增功能

- **学习页登录提醒**
  - 在学习页顶部添加未登录提醒横幅
  - 未登录用户点击"去登录"按钮可跳转到个人中心触发登录

- **徽章自动解锁**
  - 完成课程后自动检查并解锁对应徽章
  - 同步云端进度后自动解锁徽章

- **测试增强**
  - 添加登录态模拟支持（E2E测试）
  - 添加 API 层单元测试
  - 添加推荐逻辑测试覆盖率提升
  - 添加组件浅渲染测试
  - 添加路由守卫测试
  - 添加错误边界和异常处理测试

### Bug 修复

- **设置页登录状态显示**
  - 未登录时正确显示"未登录"而非默认用户名

- **首页学习进度响应式**
  - 首页学习进度在返回时自动刷新显示

- **学习统计页优化**
  - 移除"学习时长"和"连续打卡"展示（数据不完整）
  - 徽章入口改为跳转到学习统计页

---

## 2026-03-17

### 新增功能

- **首页快捷入口改版**
  - "今日学习" → "精选案例"
  - "热门资源" → "Skills大全"
  - "推荐Skill" → "我的收藏"

- **发现页 URL 参数支持**
  - 支持通过 `?tab=skill` 参数设置初始 tab
  - 支持 `?tab=case` 参数

- **修改昵称功能**
  - 用户可手动修改昵称
  - 铅笔图标点击弹出修改弹窗

### 优化

- **推荐系统优化**
  - 混合推荐算法：热度分 + 用户收藏状态 + 随机因子
  - 分数计算：`score = heat * 10 + (已收藏 ? 50 : 0) + random() * 20`
  - 未收藏高热度文章优先展示
  - 随机因子保证内容多样性
