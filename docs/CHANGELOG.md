# LeanClaw 改动日志

本文档汇总 LeanClaw 小程序的历次功能变动。

---

## 2026-03-25 (v0.6)

### 新增功能

- **微信分享功能**
  - 分享给朋友：支持所有主要页面（首页、学习、发现、我的）
  - 分享到朋友圈：支持所有主要页面
  - 新增 `usePageShare` composable 统一管理分享逻辑
  - Profile 页面添加"转发给朋友"入口按钮
  - 学习详情页、Skill 详情页、案例详情页、资源详情页均支持分享

### 优化

- **分享配置动态化**
  - 各详情页分享标题自动设置为页面内容标题
  - 使用 Vue reactive 状态确保分享配置实时更新

## 2026-03-20 (v0.4)

### 新增功能

- **返回键拦截跳转**
  - 用户在"学习"、"发现"、"我的"页面按返回键时，自动跳转到首页
  - 使用 `useBackButtonRedirect` composable 自动注册 `onBackPress` 监听
  - 首页按返回键正常退出小程序

- **batchUpdate 云函数**
  - 专用云函数支持批量增量更新 NoSQL 数据库
  - 支持 addFields、removeFields、replaceValue 三种操作
  - 使用 MongoDB $set 操作符避免字段丢失
  - 管理后台功能，仅管理员可调用

- **清除缓存功能**
  - 在"我的"页面添加清除缓存入口
  - 使用 CacheService 统一管理缓存逻辑

### 优化

- **证书功能优化**
  - 进度条显示优化
  - 支持保存证书到手机相册
  - 底部提示文字颜色改为深色

- **收藏功能云端同步**
  - 收藏数据完整同步到云端
  - 传递完整收藏数据（包含 stars 字段）
  - syncFavorites 支持完整数据同步

- **内容同步工作流**
  - 增强 AI 处理逻辑
  - 添加导读和转载出处功能
  - 支持 markdown 渲染

### Bug 修复

- 修复推荐池 fallback 逻辑
- 修复推荐排序算法，使用日期种子确保排序稳定
- 修复发现页下拉刷新错误提示问题
- 修复徽章图标和 Logo 显示问题
- 修复证书页面底部提示文字颜色

## 2026-03-17

### 新增功能

- **首页快捷入口改版**
  - "今日学习" → "精选案例"
  - "热门资源" → "Skills大全"
  - "推荐Skill" → "我的收藏"

- **发现页 URL 参数支持**
  - 支持通过 `?tab=skill` 参数设置初始 tab
  - 支持 `?tab=case` 参数

- **修改昵称功能**
  - 用户可手动修改昵称
  - 铅笔图标点击弹出修改弹窗

### 优化

- **推荐系统优化**
  - 混合推荐算法：热度分 + 用户收藏状态 + 随机因子
  - 分数计算：`score = heat * 10 + (已收藏 ? 50 : 0) + random() * 20`
  - 未收藏高热度文章优先展示
  - 随机因子保证内容多样性
