# 返回键拦截功能手动测试指南

## 测试环境
- 微信开发者工具
- 项目已构建：`npm run dev:mp-weixin`

## 功能说明
返回键拦截功能用于在用户点击返回键时，将页面重定向到首页而不是退出小程序。该功能通过拦截 `onBackPress` 生命周期实现。

## 测试步骤

### 1. 学习页面测试
1. 打开小程序，默认进入首页
2. 点击底部 TabBar "学习"
3. 点击左上角返回键（导航栏返回按钮）
4. **预期**：跳转到首页（显示"轻学Claw"），而不是退出小程序

### 2. 发现页面测试
1. 回到首页
2. 点击底部 TabBar "发现"
3. 点击左上角返回键
4. **预期**：跳转到首页

### 3. 我的页面测试
1. 回到首页
2. 点击底部 TabBar "我的"
3. 点击左上角返回键
4. **预期**：跳转到首页

### 4. 首页测试
1. 回到首页（TabBar 第一个）
2. 点击返回键
3. **预期**：退出小程序（或显示"再按一次退出"的提示）

## 测试检查点

| 测试场景 | 预期行为 | 检查点 |
|---------|---------|--------|
| 学习页返回 | 跳转首页 | 当前页面变为首页，无退出弹窗 |
| 发现页返回 | 跳转首页 | 当前页面变为首页，无退出弹窗 |
| 我的页返回 | 跳转首页 | 当前页面变为首页，无退出弹窗 |
| 首页返回 | 退出小程序 | 小程序退出或显示退出提示 |

## 常见问题

### Q: 点击返回键没有反应
A: 检查页面是否正确实现了 `onBackPress` 生命周期，并调用了 `uni.switchTab` 或 `uni.reLaunch`。

### Q: 返回到了上一个 TabBar 页面而不是首页
A: 检查重定向逻辑是否使用 `uni.reLaunch({ url: '/pages/index/index' })` 而不是 `uni.navigateBack`。
