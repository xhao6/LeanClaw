# LeanClaw Figma 生成提示词（≤500字）

```text
为移动端小程序「LeanClaw」生成设计稿+组件库（390x844）。风格：科技简约+亲和活泼；白色卡片+浅灰背景#F8F8F8；主色#1E3A5F；强调#FF6B35；大圆角12-16；线性图标。
页面/模块：TabBar=首页/学习/发现/我的。首页：Logo+标语；学习进度卡(第X天/7、进度条、按钮“继续学习”)；快捷入口(今日学习/热门资源/推荐Skill)；今日推荐列表。
学习：7天路径列表(完成绿/进行中橙/未开始灰)→每日详情。详情：Markdown阅读(标题/引用/代码块/图片视频占位)+任务checkbox；底部按钮(上一节/完成并打卡)；打卡成功返回并更新进度/徽章/证书。
发现：搜索框；Tabs(资源/案例/Skills)；信息流卡片(封面/标题/描述/tag；Skill显示Stars)；支持loading/empty；点击进入资源WebView或案例/Skill详情；收藏切换并回写列表。
我的：用户信息；统计(已学天数/完成案例/证书)；入口(收藏/证书/学习统计/设置/关于)。
页面逻辑：首页→列表→详情→返回；输出：Design Tokens、组件Variants、各页高保真稿、关键流程。
```
